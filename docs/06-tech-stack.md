# 06 — التقنيات المختارة ولماذا

> المعيار في كل اختيار: **فريق صغير، منتج عربي على الجوال، محتوى حساس للدقة، وبيانات طلاب سعوديين.** لا نختار تقنية لشهرتها؛ كل سطر هنا له سبب وبديل مرفوض.

## 1. الواجهة والتطبيق

| التقنية | لماذا | البديل الذي رفضناه |
|---|---|---|
| **Next.js 16 (App Router) + React** | تطبيق واحد للموقع العام والطالب والإدارة. الصفحات العامة تُولّد من الخادم فيفهرسها Google بالعربية (التسويق بالبحث مهم لسوق متخصص). Server Actions تقلل كود الـ API | تطبيق React منفصل + خادم منفصل: ضعف العمل وضعف الصيانة لفريق صغير |
| **TypeScript** | الأنواع من قاعدة البيانات حتى الواجهة؛ خطأ في اسم حقل يُكتشف قبل التشغيل | JavaScript: أخطاء تظهر للطلاب بدل أن تظهر لنا |
| **Tailwind CSS v4** | يدعم الخصائص المنطقية (`ms-`/`me-`، `ps-`/`pe-`، `text-start`، `inset-s`، `rounded-s`) فيعمل RTL تلقائيًا مع `<html lang="ar" dir="rtl">` دون حاجة لمتغيرات `rtl:`، والهوية كمتغيرات CSS للوضعين النهاري والليلي، وحجم CSS صغير | CSS تقليدي: يصعب ضبط RTL والوضع الليلي باتساق |
| **مكونات Radix (عبر shadcn/ui)** | مكونات وصولية (لوحة المفاتيح وقارئ الشاشة) تدعم الاتجاه RTL، والكود ملكنا بالكامل فنصممه بهويتنا | مكتبة مكونات جاهزة الشكل: كل المواقع تبدو متشابهة، وهذا ما لا تريده |
| **PWA** | يُثبَّت على الشاشة الرئيسية، ويعمل بسرعة، ويقرأ الدروس دون اتصال، **ونبيع من الويب** فلا ندفع 15–30% لمتجر Apple | تطبيق iOS/Android أصلي من اليوم الأول: تكلفة مضاعفة وعمولة المتجر على الاشتراكات |

## 2. الخادم والبيانات

| التقنية | لماذا | البديل الذي رفضناه |
|---|---|---|
| **PostgreSQL** | البيانات علائقية، والتحليلات SQL، وفيه البحث النصي والتقريبي (`pg_trgm`) والمتجهات (`pgvector`) وطابور المهام، فهو أربع خدمات في واحدة | MongoDB: العلاقات (سؤال، خيارات، مفاهيم، مصادر، محاولات) تصبح عبئًا. Firebase: صعوبة التحليلات والاستعلامات المعقدة وارتباط بمورد واحد |

| **Better Auth** | مصادقة **مستضافة عندنا** وبياناتها في قاعدتنا (مهم لنظام حماية البيانات)، تدعم رمز التحقق بالبريد وGoogle وApple والأدوار وحد المحاولات | خدمات مصادقة خارجية مدفوعة: بيانات المستخدمين خارج سيطرتنا، والتكلفة تزيد مع كل مستخدم |
| **تخزين ملفات متوافق مع S3** | الملفات الخام وصور الصفحات خاصة، تُفتح بروابط موقعة مؤقتة | حفظ الملفات في قاعدة البيانات: بطء وتضخم |

## 3. معالجة الملفات (Worker)

| التقنية | لماذا |
|---|---|
| **Python 3.12** | أفضل منظومة لمعالجة PDF وWord والعربية |
| **PyMuPDF** | استخراج النص بترتيبه المنطقي الصحيح (تجربة أولية: pdfplumber عكس النص العربي)، وصور الصفحات لشاشة المراجعة |
| **بوابة جودة لكل صفحة** | **تجربة أولية:** ملف PDF أنتجه LibreOffice تقلب حرف "لا" إلى "ال" عند الاستخراج ("الطلابي" ← "الطالبي") دون أي خطأ ظاهر. البوابة تكشف ذلك وبقايا أشكال العرض ورموز الاتجاه، وتحوّل الصفحة إلى OCR |
| **Word أولًا** | **تجربة أولية:** ملف Word تجريبي استُخرج بدقة كاملة. إن كان عندك نسخة Word من أي ملف فهي أفضل من PDF |
| **python-docx / python-pptx** | ملفات Word وPowerPoint |
| **OCR للصفحات الممسوحة** | نموذج رؤية (Claude عبر Batch بنصف التكلفة) يقرأ الصفحة ويعيد السؤال منظمًا مباشرة؛ وTesseract (`ara+eng`) كفحص مقارن رخيص. Azure Document Intelligence بديل يدعم الخط العربي اليدوي رسميًا |
| **RapidFuzz + pg_trgm** | كشف التشابه الحرفي السريع قبل الدلالي |
| **طابور داخل Postgres** (`FOR UPDATE SKIP LOCKED`) | لا نحتاج Redis أو خدمة طوابير إضافية |

## 4. الذكاء الاصطناعي

| الاستخدام | الاختيار | التفاصيل |
|---|---|---|
| استخراج الأسئلة وتصنيفها | **Claude API** (أحدث نموذج متاح) بمخرجات منظمة (JSON Schema) | مخطط صارم: لا حقل إجابة إلا مع النص الدال عليه. المعالجة الجماعية عبر **Batch API بنصف التكلفة** |
| OCR | Claude (إدخال صفحات PDF/صور) | صفحة صفحة مع درجة ثقة |
| المساعد الذكي | Claude مع **أدوات** و**استشهادات** | بث مباشر للرد، وتخزين مؤقت لتعليمات النظام (prompt caching) لخفض التكلفة، ومستوى تفكير منخفض للمحادثة العادية وأعلى للشرح المعقد |
| Embeddings (البحث الدلالي والتكرار) | **BGE-M3** (مفتوح المصدر، يُستضاف عندنا) أو **Qwen3-Embedding** | من نتائج معيار MTEB الرسمية للعربية: BGE-M3 قوي في الاسترجاع (78.9 على MIRACL-ar) وأبعاده 1024 تناسب pgvector مباشرة، وQwen3-Embedding الأفضل في التشابه الدلالي (≈89.5 على STS17 عربي). نماذج OpenAI وVoyage أضعف في العربية في هذه المعايير. **الاستضافة الذاتية تبقي النص داخل بيئتنا.** القرار النهائي بعد اختبار على 200–500 زوج من أسئلتنا |

**ضوابط:**
- كل الـ prompts في ملفات بأرقام نسخ، وكل استدعاء يُسجَّل بالنموذج والنسخة والتكلفة.
- **مجموعة تقييم (evals)** قبل أي تغيير على prompt أو نموذج: دقة الاستخراج، والاستشهاد، ورفض الاختلاق.
- لا نرسل للنموذج اسم الطالب أو بريده: فقط نص السؤال والمحتوى. **واجهة Claude لا تتيح معالجة داخل المملكة** (المواقع المتاحة: الولايات المتحدة أو عالمي)، فتذكر سياسة الخصوصية ذلك صراحة، ويُعامل كنقل بيانات خارج المملكة بضوابطه.
- حصة يومية للمساعد لكل مستخدم، ولوحة تكلفة يومية.

## 5. البحث والتعلم

| التقنية | لماذا |
|---|---|
| **بحث هجين داخل Postgres** | نصي (`tsvector` بإعداد `simple` على المفتاح المطبّع + حذف خفيف للسوابق و/ف/ب/ك/ل+ال في التطبيق) + تقريبي (`pg_trgm` يتحمل الأخطاء الإملائية) + دلالي (`pgvector`)، مدمجة بـ Reciprocal Rank Fusion. ننتقل لمحرك منفصل (Meilisearch أو Typesense) فقط إذا احتجنا بحثًا فوريًا أثناء الكتابة على نطاق كبير |
| **لماذا لا نستخدم إعداد البحث العربي المدمج؟** | **تجربة أولية على PostgreSQL 16:** المُجذِّع العربي المدمج يعطي جذورًا مختلفة للكلمة نفسها مع "ال" وبدونها، فالبحث عن "توجيه" **لا يجد** "التوجيه الطلابي"، و"موجه" لا يجد "الموجه الطلابي"، و"مدرسة" لا تجد "والمدرسة". هذه بالضبط أهم كلمات المجال |
| **جدول مرادفات المجال** | المرشد ↔ الموجه، الإرشاد ↔ التوجيه، وغيرها. يُطبق في البحث وكشف التكرار، فتتجمع أسئلة المسمى القديم مع الجديد |
| **إعداد اللغة لقاعدة البيانات** | تُنشأ القاعدة بـ `C.UTF-8` أو ICU. **تجربة أولية:** مع `LC_CTYPE=C` يعيد `pg_trgm` صفرًا من المقاطع للنص العربي، فيفشل البحث التقريبي بصمت. يُفحص آليًا عند التشغيل |
| **مُطبِّع عربي خاص** في `packages/core` | يحل مشكلة ملف 1440 فعليًا: NFKC، والحروف الفارسية، والتطويل، والتشكيل، وأشكال الألف/الياء/التاء، والأرقام |
| **ts-fsrs** (FSRS-6) | تنفيذ مفتوح (MIT) لأحدث خوارزمية تكرار متباعد. على معيار ~350 مليون مراجعة، خطؤها في التنبؤ بالنسيان أقل بكثير من البدائل (log loss 0.346 مقابل 0.469 لخوارزمية Duolingo). نضبط أقصى فاصل **بعدد الأيام المتبقية للاختبار** فلا يُجدول شيء بعده، ونخلط الخيارات في كل مراجعة، ونسجل كل مراجعة لتخصيص المعاملات لكل طالب لاحقًا |

## 7. الاستضافة (قرار يعتمد على الخصوصية)

نظام حماية البيانات الشخصية **لا يفرض** استضافة البيانات داخل المملكة على كل منصة تجارية، لكنه يقيّد النقل للخارج، والاستضافة داخل المملكة تبسّط الالتزام وتبني الثقة. لذلك:

**ما المتاح (من قوائم المناطق في أدوات المزودين البرمجية ومستودعاتهم الرسمية، أكتوبر 2026؛ لم تُفتح صفحات الأسعار والخدمات):**

| المزود | داخل المملكة؟ |
|---|---|
| **Oracle Cloud** | ✅ منطقتا **جدة** و**الرياض** (عامة) |
| **Google Cloud** | ✅ **الدمام** (me-central2)، لكن **بشروط وصول خاصة** |
| **Microsoft Azure** | ⏳ منطقة "Saudi Arabia East" ظهرت في أدوات المطورين في أبريل 2026، وتوافرها العام غير مؤكد |
| **AWS** | ❌ لا منطقة سعودية متاحة بعد (الأقرب البحرين والإمارات) |
| Supabase / Neon (Postgres مُدار) | ❌ لا مناطق في الشرق الأوسط |
| Vercel | ❌ الأقرب دبي |

| الخيار | المكونات | متى |
|---|---|---|
| **أ) داخل المملكة (موصى به للإطلاق)** | Oracle Cloud (جدة/الرياض) أو Google Cloud الدمام: حاويات للموقع والـ Worker + PostgreSQL + تخزين ملفات | الإطلاق العام والدفع |
| **ب) الأسرع للتطوير** | استضافة Next.js + Postgres مُدار في أقرب منطقة + حاوية للـ Worker | التطوير والتجربة المغلقة، **بلا بيانات طلاب حقيقية** |

لأن كل شيء في Docker، الانتقال من (ب) إلى (أ) نقل لا إعادة بناء. **يُحسم الخيار وأسعاره عند المرحلة 10** بعد التحقق من الخدمات المتاحة فعليًا في المناطق السعودية حينها.

## 8. الدفع والتجارة

- بوابة دفع سعودية مرخصة (مثل Moyasar أو Tap أو HyperPay): **مدى + Apple Pay** إلزاميان، ثم فيزا/ماستركارد. تُقارن الرسوم عند التنفيذ.
- الأسعار شاملة ضريبة القيمة المضافة 15%، والفوترة الإلكترونية (فاتورة) عند الوصول لحد التسجيل.
- البيع من الويب (وليس داخل تطبيق iOS) لتجنب عمولة المتجر.
- صفحة واضحة لهوية البائع والأسعار والاسترجاع (نظام التجارة الإلكترونية).

> التجارب الأولية المذكورة هنا أُجريت على عينات صغيرة مصنوعة في بيئة البحث، وسكربتاتها في [`research/prototypes/`](../research/prototypes/). تُعاد على ملفاتك الحقيقية في المرحلة 2.

## 9. ملخص في سطر
**Next.js 16 + TypeScript + Tailwind 4 + PostgreSQL (بحث ومتجهات وطابور) + Prisma + Better Auth + Python Worker + Claude API + BGE-M3 + ts-fsrs + PWA + Docker.**
