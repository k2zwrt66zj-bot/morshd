# SWAA — منصة التحضير لاختبار الرخصة المهنية (الموجّه / المرشد الطلابي)

منصة ويب عربية، تعمل على الجوال أولًا، تُعد خريجي علم الاجتماع والخدمة الاجتماعية وعلم النفس لاختبار الرخصة المهنية للوظائف التعليمية: **الاختبار التربوي العام** و**الاختبار التخصصي (الإرشاد الطلابي)**.

ليست بنك أسئلة فقط، بل **مدرّب شخصي**: يقيس المستوى، ويعلّم المفهوم، ويعيد الأخطاء حتى الإتقان، ويخطط كل يوم حتى موعد الاختبار. وكل معلومة فيه مربوطة بمصدرها.

> المنصة غير تابعة لهيئة تقويم التعليم والتدريب ولا لوزارة التعليم.

## الحالة الحالية

**المرحلة 0: التخطيط والتأسيس.** الوثائق ومخطط قاعدة البيانات جاهزة. البناء يبدأ بعد اعتماد المؤسس.
