# 07 — خط معالجة المحتوى (Content Pipeline)

> المبدأ الحاكم: **لا شيء يصل للطالب دون مراجعة بشرية، ولا إجابة تُخترع.**
> رفع ملف ≠ نشر محتواه.

```
رفع الملف ─▶ استخراج النص ─▶ تنظيف وتطبيع ─▶ تقطيع وتصنيف المقاطع
   │                                                     │
   │                                                     ▼
   │                                    استخراج الأسئلة والمفاهيم (LLM + Schema)
   │                                                     │
   │                                                     ▼
   │                                  ربط بالمجال/المحور/المفهوم + تقدير الصعوبة
   │                                                     │
   │                                                     ▼
   │                         كشف التكرار والتشابه (داخل الملف ومع البنك المنشور)
   │                                                     │
   ▼                                                     ▼
سجل المصدر (Source)                      طابور المراجعة البشرية (Admin › المراجعة)
                                                         │
                               اعتماد / تعديل ثم اعتماد / دمج مع سؤال قائم / رفض
                                                         │
                                                         ▼
                                                 نشر (Question + Occurrence)
```

## 1. المراحل بالتفصيل

| # | المرحلة | ماذا يحدث | المخرجات | من ينفذها |
|---|---------|-----------|----------|-----------|
| 1 | **الرفع** | حفظ الملف في تخزين خاص، حساب `sha256` لمنع تكرار رفع نفس الملف، ربطه بمصدر (نوعه، سنته، موثوقيته) | `File`, `Source` | المؤسس |
| 2 | **استخراج النص** | PDF نصي ← طبقة النص. PDF ممسوح/صور ← OCR عبر نموذج رؤية (Claude) صفحة صفحة مع درجة ثقة. Word ← python-docx. PowerPoint ← python-pptx. صور ← رؤية. تصدير تيليجرام (HTML/JSON) ← محلل خاص | `ContentChunk.textRaw` لكل صفحة | Worker |
| 3 | **التطبيع العربي** | NFKC لفك "أشكال العرض" العربية، تحويل الحروف الفارسية (ی ھ ک) لعربية، حذف التطويل والتشكيل للبحث، توحيد الألف/الياء/التاء المربوطة **في نسخة البحث فقط**، الأرقام الهندية ← عربية. حذف ضجيج تيليجرام (Forwarded from، الطوابع الزمنية، روابط القنوات) وإزالة أسماء الأشخاص (PII) | `textNorm` | Worker |
| 4 | **التقطيع والتصنيف** | كل مقطع يُصنف: سؤال / شرح / محتوى دراسي / نصيحة / ضجيج | `ChunkKind` | LLM |
| 5 | **استخراج العناصر** | لكل سؤال: نص السؤال الخام حرفيًا + صياغة فصحى مقترحة + الخيارات كما وردت + هل الخيارات مكتملة + الإجابة **فقط إن وردت** مع النص الدال عليها + حالة الإجابة + الشرح إن وُجد + أعلام المشاكل | `ExtractedQuestion` | LLM بـ Structured Outputs |
| 6 | **التصنيف** | اقتراح المجال/المحور/الموضوع/المفاهيم/الصعوبة مع درجة ثقة | حقول `suggested*` | LLM |
| 7 | **كشف التكرار** | (أ) تطابق تام بعد التطبيع ← (ب) تشابه حروف trigram ← (ج) تشابه دلالي embeddings ← (د) حكم LLM للحالات الحدّية: نفس السؤال؟ نفس المفهوم بصياغة أخرى؟ مختلف؟ | `clusterKey`, `nearestQuestionId`, `similarity` | Worker + LLM |
| 8 | **المراجعة البشرية** | شاشة جنبًا لجنب: صورة الصفحة الأصلية ↔ الحقول المستخرجة. مرتبة من الأقل ثقة. اختصارات لوحة مفاتيح. | `Review` | المؤسس/محرر |
| 9 | **النشر** | سؤال جديد أو "ظهور" (Occurrence) إضافي لسؤال قائم ← يرفع عدّاد التكرار | `Question`, `AnswerOption`, `QuestionOccurrence` | النظام |

## 2. قواعد صارمة للذكاء الاصطناعي في الاستخراج

1. **لا يكمل إجابة ناقصة.** إذا لم يذكر الملف الإجابة ← `answerStatus = MISSING`.
2. **"اخترتُ كذا" ليست مفتاح إجابة.** تُسجل `CANDIDATE_REPORTED` لأنها اختيار المختبر وقد تكون خاطئة.
3. يجوز للنموذج أن **يقترح** إجابة في حقل منفصل `aiSuggestedAnswer` مع التعليل. يراه المراجع فقط بوسم واضح، ولا يصل للطالب إلا بعد تحقق بشري من مرجع.
4. **النص الخام محفوظ دائمًا** (`rawExcerpt`) بجانب الصياغة المحسنة، لتتمكن من التحقق.
5. **الأنظمة المتغيرة** (مثل قواعد السلوك والمواظبة وعدد درجات المخالفات) تُوسم `outdated_regulation` إذا كانت من نسخة قديمة، ويُربط السؤال بـ `regulationVersion`.
6. كل استدعاء للنموذج يسجل: النموذج، رقم نسخة الـ prompt، التكلفة، في `IngestionJob.metrics`، لإعادة التشغيل والمقارنة.

## 3. التمييز بين أنواع الأسئلة (يظهر للطالب كشارة)

| الشارة للطالب | `origin` | المعنى |
|---|---|---|
| 📄 من ملف | `SOURCE_VERBATIM` | ورد نصًا في مصدر |
| 🧠 استرجاع مختبرين | `SOURCE_RECONSTRUCTED` | تذكّره مختبرون وأعدنا صياغته وأكملنا خياراته بعد مراجعة |
| ✏️ معدّل | `ADAPTED` | صياغة جديدة لسؤال سابق، ويرتبط بالأصل |
| 🎯 تدريبي | `TEAM_AUTHORED` | كتبه فريق المحتوى لتغطية مفهوم |
| ✨ مولّد بالذكاء الاصطناعي | `AI_GENERATED` | ولّده النموذج وراجعه إنسان |
| 🔁 متكرر ×N | `occurrenceCount ≥ 2` | ظهر في N مصادر مستقلة. **دليل تكرار، وليس وعدًا بظهوره في الاختبار** |

ومع كل إجابة، درجة ثقة: ✅ موثقة بمرجع، 🤝 اتفاق مصادر، ⚠️ مصدر واحد، ❓ مختلف عليها.

## 4. تحليل أولي للملف الذي رفعته (تجربة على أرض الواقع)

**الملف:** "أسئلة اختبار كفايات الإرشاد الطلابي لعام 1440"، تجميع من قناة تيليجرام. 10 صفحات، نُشر في نوفمبر 2018.

**ما اكتشفته فيه، وكيف يتعامل معه النظام:**

| الملاحظة | مثال من الملف | المعالجة في الـ Pipeline |
|---|---|---|
| ترميز النص "أشكال عرض" عربية + حروف فارسية (ی، ھ) | النص المستخرج خامًا غير قابل للبحث | التطبيع (المرحلة 3). بدونها يفشل البحث وكشف التكرار تمامًا |
| أسئلة **مسترجعة من الذاكرة** بلهجة عامية | "فيه سؤال اللي م يطالع المعلم بعينه…" | `SOURCE_RECONSTRUCTED` + صياغة فصحى مقترحة + النص الخام محفوظ |
| خيارات ناقصة | "ناسي الخيارات"، "مااتذكر إلا أول خيار" | `optionsComplete=false` ← لا يُنشر حتى تكتمل الخيارات بمراجعة |
| إجابة = اختيار المختبر | "الإرشاد النفسي ولا الأسري؟ اخترت النفسي" | `CANDIDATE_REPORTED` وليس مفتاحًا |
| خيارات لا تتضمن الإجابة الصحيحة غالبًا | "غدة مسؤولة عن النمو: اللمفاوية / العصبية" (الإجابة العلمية المعروفة هي النخامية وليست في الخيارات المذكورة) | `MISSING` + اقتراح AI للمراجع فقط ← تحقق من مرجع |
| **تكرار كثيف** لنفس السؤال | "الحاجة للتقدير والحب والأمان: نفسية أم اجتماعية؟" تكررت 5 مرات بسبب إعادة التوجيه؛ تجربة كلب بافلوف 4 مرات؛ موقف "الحصة السادسة/السابعة" 3 مرات؛ شبكة الاتصال "العجلة" 3 مرات؛ حالة التوحد 3 مرات | دمج في سؤال واحد، والتكرار **بين ملفات مستقلة** فقط يرفع عدّاد "متكرر" (لا نحسب إعادة التوجيه داخل نفس الملف) |
| ضجيج تيليجرام وأسماء أشخاص | "[Dream, 30.11.18 17:59] Forwarded from …" | حذف تلقائي + إزالة الأسماء |
| معلومة نظامية **تقادمت فعلًا** | "قسمت وزارة التعليم درجات المخالفات إلى 6 درجات" | البحث يشير إلى أن الست درجات من قواعد 1437/1438 للمتوسط والثانوي. الإصدار الحالي هو **قواعد السلوك والمواظبة لطلبة التعليم العام — الإصدار الخامس 1447هـ**، وتقسيمه مختلف (الأرجح 5 درجات للمتوسط والثانوي و4 للابتدائي، **بانتظار التحقق من ملف الوزارة نفسه**). السؤال يُوسم `outdated_regulation` ويُربط بإصداره، ولا يُنشر بإجابة حتى نقرأ الملف الرسمي |
| أسئلة بصرية | "رسم بياني لدرجات الطلاب… صدق تباعدي" | `IMAGE_BASED` ← يحتاج إعادة رسم الشكل |
| نصائح مختبرين | "ذاكر من ملزمة منى الحربي… وكتاب فهد البطين… والنظريات السلوكية والعقلانية" | `ADVICE`: لا تُنشر، لكنها إشارة لأولويات المحتوى. (لم أجد المرجعين في البحث، فإن كانا ضمن ملفاتك فسيُسجلان كمصدرين) |
| عناصر غير جادة | "من مهام المرشد: أخذ العلوك من الطلاب…" | `NOISE`/رفض |

**المحاور التي تظهر بوضوح من هذا الملف وحده** (مؤشر أولي لا أكثر):
تعديل السلوك (تعزيز/عقاب سلبي وإيجابي/تكلفة الاستجابة/الإقصاء/التحصين التدريجي/النمذجة/العقد السلوكي) — نظريات النمو (بياجيه، إريكسون) — نظريات التعلم (الإشراط الكلاسيكي والإجرائي، التعلم الاجتماعي) — نظريات الإرشاد (التحليل النفسي، العقلاني الانفعالي، الواقع، السيكودراما، لعب الدور، المرايا) — القياس والإحصاء (النزعة المركزية، معاملات الارتباط بيرسون/سبيرمان، الصدق التباعدي، الاختبارات الإسقاطية، وكسلر) — التربية الخاصة (التوحد، الإعاقة الفكرية، صعوبات التعلم، الموهبة والإثراء الأفقي) — أخلاقيات المهنة وإجراءاتها (السرية، الإذن بالتسجيل، الالتزام بالمواعيد، الإحالة، الميثاق الأخلاقي) — مهارات المرشد وسماته (التعاطف، الإنصات، المرونة) — ديناميات الجماعة (شبكات الاتصال: العجلة/الدائرة/السلسلة) — التنظيمات المدرسية (لجان التوجيه، مهام الموجه، قواعد السلوك والمواظبة) — الملاحظة (العابرة/المنظمة) — الحاجات (ماسلو).

**أهم استنتاج تصميمي:** الاختبار يعتمد بكثافة على **المواقف** و**التمييز بين مفاهيم متشابهة** (عقاب سلبي أم تكلفة استجابة أم إقصاء؟ تحصين تدريجي أم غمر؟ نمذجة أم مرايا أم لعب دور؟). لذلك أضفت للمنتج قسم "مفاهيم متشابهة" وجدول `ConceptRelation`.

## 5. سياسة الحقوق والمحتوى المسترجع (مهم قانونيًا وتعليميًا)

### الملازم والتجميعات التجارية
كثير من الملازم والتجميعات المتداولة منتجات تجارية لجهات أخرى. **تحليلها مسموح، ونسخها لا.** لذلك كل مصدر يُسجل بحقوق استخدامه:

| الحقوق | المعنى | ماذا نفعل به |
|---|---|---|
| `OWNED` | كتبته أنت أو فريقك | ينشر مباشرة بعد المراجعة |
| `OFFICIAL_PUBLIC` | وثائق رسمية (الهيئة، الوزارة) | نستشهد به ونقتبس منه باختصار مع ذكر المصدر |
| `PERMITTED` | لديك إذن من صاحبه | ينشر حسب الإذن |
| `ANALYSIS_ONLY` (الافتراضي) | ملزمة/تجميعات لجهة أخرى | نستخرج منه **المفاهيم وتكرارها** فقط، ونكتب أسئلة أصلية، ولا ننشر نصه |

### الأسئلة المسترجعة من الاختبار

الأسئلة المسترجعة دليل ممتاز على **المفاهيم** التي يركز عليها الاختبار. لكن نشر نص أسئلة اختبار رسمي حرفيًا قد يخالف شروط الجهة المنظمة. التوصية:

- نستخدم الاسترجاعات لقياس **تكرار المفاهيم** وبناء خريطة الأولويات.
- نكتب أسئلة تدريبية **أصلية** تقيس نفس المفهوم بصياغات متعددة.
- عند نشر سؤال مسترجع، يكون بصياغتنا وبعد التحقق من الإجابة من مرجع علمي أو نظامي.

هذا أفضل تعليميًا أيضًا: الطالب يتعلم المفهوم بدل حفظ سؤال بعينه.
