# 08 — خطة البناء خطوة بخطوة

> **التوقيت:** الاختبار التخصصي يبدأ 18 أكتوبر 2026 (بعد ~12 يومًا)، والعام 6 نوفمبر. لن نَعِد طلاب هذه الدورة بمنصة كاملة. **الهدف: نسخة تجريبية مغلقة قبل نافذة يناير 2027 تقريبًا، وإطلاق عام قبلها بأسابيع كافية للمذاكرة.** (يتأكد الموعد من إعلان الهيئة.)
>
> القاعدة: **المحتوى أولًا.** جودة المنصة = جودة بنك الأسئلة. لذلك نبني خط معالجة الملفات ولوحة المراجعة قبل الواجهات اللامعة، لنبدأ معالجة ملفاتك مبكرًا بينما تُبنى بقية المنصة.

كل مرحلة تنتهي بشيء **يعمل فعليًا** ويمكنك تجربته، ومعايير قبول واضحة.

---

### المرحلة 0 — التأسيس (الآن)
- [x] تحليل المنتج والمتطلبات، الهوية، المعمارية، مخطط قاعدة البيانات، هيكل الصفحات (هذه الوثائق)
- [x] تحليل أول ملف (أسئلة 1440)
- [ ] **قرارك:** اعتماد الاسم والهوية والتقنيات
- [ ] **أنت:** رفع الملفات إلى `content/inbox/` (الطريقة في README)

### المرحلة 1 — الهيكل الأساسي
- Monorepo + Next.js + TypeScript + Tailwind + RTL + الوضع الليلي
- design tokens ومكونات الهوية الأساسية + صفحة `/brand`
- قاعدة البيانات + الهجرات + زرع التصنيف الرسمي (المجالات والمحاور)
- المصادقة (بريد + رمز، Google) والأدوار
- CI: فحص الأنواع، الاختبارات، البناء
- **القبول:** تسجيل دخول يعمل على الجوال، صفحة `/brand` بالوضعين، CI أخضر

### المرحلة 2 — خط معالجة الملفات + لوحة المراجعة ⭐
- Worker بايثون: استخراج النص، OCR، التطبيع العربي، التقطيع، الاستخراج المنظم، التصنيف، كشف التكرار
- لوحة الإدارة: رفع، حالة كل ملف، **طابور المراجعة** (الأصل ↔ المستخرج)، اعتماد/دمج/رفض، إدارة الأسئلة والتصنيف
- **تشغيل الـ pipeline على كل ملفاتك** ← تقرير: كم سؤالًا، كم مكررًا، كم يحتاج تحققًا، خريطة تكرار المفاهيم
- **القبول:** ملف 1440 يعطي نتائج مطابقة لعينة ذهبية مراجعة يدويًا؛ لا يوجد سؤال منشور بإجابة `MISSING`

### المرحلة 3 — بنك الأسئلة والتدريب
- الفلاتر الكاملة، جلسة تدريب بتصحيح فوري، سؤال منفرد، حفظ، علامة، إبلاغ
- شاشة الشرح: لماذا الصحيح صحيح ولماذا كل خيار خطأ، المفهوم، المصدر، شارات الأصل والثقة
- **المراجعة الذكية للأخطاء (FSRS)** + صفحة "راجع"
- **القبول:** طالب يحل 30 سؤالًا على الجوال بلا تأخير ملحوظ؛ الخطأ يعود في موعده

### المرحلة 4 — تحديد المستوى ولوحة الطالب
- الترحيب (Onboarding)، اختبار تحديد المستوى، نتيجة بنقاط القوة/الضعف
- محرك الإتقان، صفحة "اليوم"، السلسلة، الإحصائيات
- **القبول:** نتيجة تحديد المستوى تظهر أضعف 3 محاور بشكل منطقي على بيانات تجريبية

### المرحلة 5 — الاختبارات التجريبية
- القوالب (عام، تخصصي، شامل، سريع، حسب محور، مخصص)، مؤقت من الخادم، حفظ تلقائي، تجميع حسب الأوزان
- صفحة النتيجة: الدرجة، الوقت، المجالات، المحاور الضعيفة، المقارنة بالمحاولات السابقة، مراجعة الأسئلة
- **القبول:** انقطاع النت أو تحديث الصفحة أثناء الاختبار لا يضيع شيئًا

### المرحلة 6 — "ذاكر" و"المراجعة المكثفة"
- محرر دروس في الإدارة، وتوليد **مسودات** الدروس من ملخصاتك المرفوعة (تُراجع قبل النشر)
- صفحة المحور: شرح، نقاط، مصطلحات (بطاقات)، مفاهيم متشابهة، أسئلة مرتبطة ومتكررة، اختبار قصير
- المراجعة المكثفة: الأهم، المتكرر، الأخطاء الشائعة، صياغات بديلة، "الساعة الأخيرة"

### المرحلة 7 — خطة المذاكرة
- مولّد الخطة + إعادة التخطيط الليلية + تقويم الخطة + ربط المهام بالجلسات
- **القبول:** اختبارات آلية لسيناريوهات (7 أيام/ساعة يوميًا، 60 يومًا/3 ساعات، طالب متأخر…)

### المرحلة 8 — المساعد الذكي والبحث
- البحث الهجين، والمساعد بالأدوات والاستشهادات والحصص
- **مجموعة تقييم (eval)** من 100 سؤال حقيقي للطلاب: نقيس الدقة والاستشهاد ورفض الاختلاق قبل الإطلاق
- **القبول:** لا إجابة بدون استشهاد أو وسم "غير موثق"

### المرحلة 9 — الاختبار الشامل والجودة
- Playwright لكل التدفقات على مقاسات الجوال، وفحص وصولية، واختبار أداء، ومراجعة أمنية
- تجربة مغلقة مع 20–50 طالبًا حقيقيًا، وتحليل الأسئلة المبلغ عنها ومعاملات التمييز

### المرحلة 10 — الإطلاق
- الاستضافة، النطاق، البريد، المراقبة، النسخ الاحتياطي، سياسة الخصوصية والشروط
- الدفع (بوابة سعودية: مدى، Apple Pay، STC Pay)
- صفحات أدلة مجانية للتسويق عبر البحث

## ما بعد الإطلاق (مقترحات للنمو)
- **"بعد اختبارك":** نموذج منظم يملؤه المختبر بعد الاختبار عن **المفاهيم** التي واجهها (وليس نص الأسئلة)، فتتحدث خريطة الأولويات كل دورة.
- مسارات إضافية بنفس المنصة: رائد النشاط، وغيرها.
- مجموعات مذاكرة وتحديات أسبوعية.
- تطبيق جوال أصلي إذا احتجنا إشعارات أقوى (الـ PWA يكفي للبداية).
