# 05 — هيكل الصفحات وتجربة المستخدم

## 1. مبادئ التجربة

1. **الجوال أولًا:** يُصمم كل شيء لشاشة 360px ثم يتوسع. أزرار الإجابة كبيرة (48px على الأقل) وفي متناول الإبهام.
2. **"ماذا أفعل الآن؟" دائمًا واضح:** الصفحة الرئيسية داخل التطبيق اسمها **"اليوم"**، وتعرض مهمة اليوم من الخطة بزر واحد: "ابدأ".
3. **سرعة:** فتح السؤال التالي فوري (يُجلب مسبقًا). لا انتظار بين الأسئلة.
4. **الصدق في المحتوى:** شارة الأصل ودرجة ثقة الإجابة ظاهرة في كل سؤال، والتكرار يُعرض على مستوى المفهوم فقط ولا يُقدَّم كوعد.
5. **التعلم لا الحفظ:** بعد كل إجابة: لماذا الصحيح صحيح، لماذا كل خيار خاطئ، المفهوم المرتبط، وزر "اشرح لي أكثر" (المساعد الذكي).
6. **عربي أصيل:** RTL كامل، أرقام عربية أو هندية حسب تفضيل المستخدم، تاريخ هجري وميلادي لموعد الاختبار.

## 3. التدفقات الأساسية

### أ) أول استخدام
```
الصفحة الرئيسية ─▶ "جرّب سؤالًا" (بدون تسجيل) ─▶ تسجيل (رمز للبريد)
 ─▶ الترحيب + الموافقات ─▶ التشخيص (10–12 دقيقة، يمكن الإيقاف والاستكمال)
 ─▶ النتيجة + نقاط القوة/الضعف ─▶ "أنشئ خطتي" ─▶ اليوم: مهمة اليوم الأولى
```

### ب) حلقة يومية (الهدف: 20–60 دقيقة)
```
اليوم ─▶ مراجعة الأخطاء المستحقة (5 دقائق) ─▶ درس المحور (ذاكر)
 ─▶ تدريب على المحور (20–40 سؤالًا) ─▶ تحديث الإتقان والخطة ─▶ 🔥 السلسلة
```

### ج) شاشة السؤال (التدريب)
```
┌─────────────────────────────────────┐
│ ‹ 7 / 30          ⏱ 00:42      ☆ ⚑  │  ☆ حفظ   ⚑ علامة للمراجعة
│ تعديل السلوك › الإقصاء              │
│ [شارة الأصل] · [ثقة الإجابة]        │
│                                     │
│ طالب تحدث مع زميله أثناء الدرس فأخرجه│
│ المعلم من الفصل لبقية الحصة. ما     │
│ الأسلوب المستخدم؟                   │
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ أ  العقاب الإيجابي               │ │
│ └─────────────────────────────────┘ │

│ │ ب  تكلفة الاستجابة               │ │
│ └─────────────────────────────────┘ │

│ │ ج  الإقصاء                       │ │
│ └─────────────────────────────────┘ │

│                                     │
│  ثقتك؟  [متأكد] [غير متأكد] [تخمين] │  ← اختياري؛ إن تُخطي يُقدَّر من سرعة الإجابة

```
(السؤال والخيارات مثال توضيحي لتصميم الشاشة فقط، وليس محتوى معتمدًا.)

### د) المراجعة الذكية للأخطاء
- يدخل السؤال لقائمة "تحتاج مراجعة" إذا **أخطأت** فيه، أو أصبت لكن قلت **"تخمين"** (أو أصبت ببطء شديد).
- خوارزمية FSRS (التكرار المتباعد) تحدد موعد عودته: غدًا، ثم بعد 3 أيام، ثم أسبوع… حسب أدائك.
- العودة تكون **بسؤال شقيق** يقيس الشيء نفسه بصياغة أخرى إن توفر، وبترتيب خيارات مختلف دائمًا، حتى تتقن المفهوم لا نص السؤال.
- يخرج من القائمة بعد إصابته عدة مرات متباعدة ← "أتقنته ✓".
- لا يُجدول شيء بعد موعد اختبارك، وتُضغط الفترات قبله تلقائيًا.

## 4. الهوية في الواجهة (ملخص — التفاصيل في 02-brand)
- خط واجهة عربي واضح جدًا على الجوال، وأرقام جدولية في المؤقت والإحصائيات.
- لونان أساسيان فقط + محايدات دافئة، ولون للنجاح وآخر للخطأ لا يعتمدان على اللون وحده (أيقونة ✔/✘ دائمًا).
- الوضع الليلي: يتبع النظام تلقائيًا مع زر تبديل.
- الحركة: انتقالات قصيرة (150–200ms)، احتفال خفيف عند إتقان محور.
